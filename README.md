# Auto_Turret_Range
자동 포탑 + 타겟 추적 + 사격 시스템
Auto Turret Range

Unity를 활용하여 구현한 자동 포탑 사격 시스템입니다.
포탑이 이동하는 타겟을 추적하고, 정확히 조준했을 때 발사체를 발사합니다.

#프로젝트 개요

이 프로젝트는 Transform 계층 구조와 회전 시스템을 기반으로
자동으로 타겟을 추적하고 발사하는 포탑을 구현하는 것을 목표로 합니다.

#주요 기능
1.타겟 이동

타겟은 포탑을 중심으로 원형 궤도를 따라 이동합니다.
또한 Sin 함수를 이용하여 위아래로 부드럽게 움직입니다.

2.포탑 회전

포탑은 두 단계의 회전을 사용합니다.

Yaw 회전 : 좌우 방향으로 회전 (World 기준)
Pitch 회전 : 상하 방향으로 회전 (Local 기준)

3.조준 판정

Raycast를 사용하여 포탑이 타겟을 정확히 바라보고 있는지 판단합니다.
Muzzle_Point.forward 방향을 기준으로 판정합니다.

4.발사 시스템

포탑이 조준 상태일 때 일정 간격으로 발사체를 생성합니다.
발사체는 Object Pooling 방식으로 재사용됩니다.

#핵심 개념

Transform 계층 구조를 활용하여 회전을 분리했습니다.
Yaw_Pivot은 좌우 회전을 담당하고, Pitch_Pivot은 상하 회전을 담당합니다.

발사 방향은 Muzzle_Point의 forward 벡터를 기준으로 합니다.

회전은 Quaternion과 Euler Angle을 활용하여 부드럽게 처리했습니다.
